# CYBER PULSE 2099: NEON VANGUARD

Um jogo arcade espacial no estilo **Cyberpunk / Synthwave** desenvolvido em HTML5 Canvas, CSS3 (Glassmorphism) e JavaScript puro, com motor de áudio procedural via **Web Audio API**.

## 🎮 Como Jogar

- **Mover Nave:** `W`, `A`, `S`, `D` ou Setas do Teclado
- **Mirar e Atirar:** Mouse + Botão Esquerdo
- **Esquiva (Dash):** `ESPAÇO` (invulnerabilidade temporária)
- **Onda EMP:** `E` (destrói projéteis inimigos e paralisa inimigos)
- **Overdrive:** `Q` (dobra o dano e aumenta a cadência quando a barra estiver cheia)
- **Trocar Armas:** `1` a `4`
- **Pausa:** `ESC`

## 🚀 Executar Localmente

Basta abrir o arquivo `index.html` diretamente no navegador. Não requer dependências ou servidor.
